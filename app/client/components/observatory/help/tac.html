Agents, tasks and actions

These come from explicit local reports. Session IDs and source times stay visible. Saved reports become stale until a real update arrives.

There is no automatic Codex desktop task stream. A process is not a logical agent. Actions show safe tool names, without prompts, command arguments or terminal output.

Local process resources

CPU, resident memory and disk counters belong to the named local process. CPU 100% means one logical core. Memory may include shared pages.

Network counters can be partial or unavailable. A missing value is not zero. Charts keep up to two minutes of real samples and preserve missing samples as gaps.

Ownership and shared runtimes

A reported command link must match PID, start time, user and executable. Child ownership follows only the current verified parent tree.

Command-root totals exclude children. Each child keeps its own metrics. Shared desktop totals and remote model computation are not split into agent estimates.

Using this app

The sidebar switches full-area views. Processes has Table and Tree views, with selection, filters and independent tree controls. The app updates automatically.

All measurements and reports stay on this Mac. Collection and the private local event socket continue while Help is open. Normal Quit stops them. The app has no HTTP server, Python runtime or external telemetry.

Native Command-1 through Command-5 section shortcuts and File Close are waiting for the framework action contract. Returning from Help reloads the view, so UI filters and selection may reset. Measured history belongs to the running app and continues through navigation.
