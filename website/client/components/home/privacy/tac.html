What it never does

  • Read prompts, session transcripts or terminal output.
  • Run an HTTP server, a Python runtime or external telemetry.
  • Install a persistent service or change OS security settings.
  • Guess which agent owns a shared process.

What it cannot see

  • Cloud agent sessions, such as Codex cloud threads. They run remotely and send no local events.
  • Remote model computation. Only local processes are measured.
  • Work from a desktop client that is merely open. That is not counted as active work.
  • Tasks without an explicit, supported event source.
