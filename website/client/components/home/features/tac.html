• What's running

    One page counts current work only: working agents, active sessions, running tools and active harnesses.

  • Sessions you can trace

    Agents, tasks and actions come from explicit local reports. Session IDs and source times stay visible.

  • Measured process resources

    CPU, resident memory and disk counters belong to the named local process. Charts keep real samples and show gaps where samples are missing.

  • Safe action names

    Current actions show safe tool names, without prompts, command arguments or terminal output.

  • Shared stays shared

    Shared desktop processes and remote model work are not split into invented per-agent totals. Unassigned processes stay separate.

  • Honest gaps

    Missing, denied, stale and reset measurements keep their labels. A missing value is shown as missing, not as zero.
