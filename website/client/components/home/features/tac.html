• What's running

    Each verified active agent appears on its own, so you can see at a glance who is working and on what.

  • Sessions by their real IDs

    Codex chats and Claude sessions keep their exact provider conversation ID and source time. Records are never merged by title.

  • Measured process resources

    CPU, resident memory and disk counters belong to the named local process, tracked by executable, PID, start time and parent.

  • Safe action names

    Current actions show safe tool names, without prompts, command arguments or terminal output.

  • Shared stays shared

    Shared desktop processes and remote model work are not split into invented per-agent totals. Unassigned processes stay separate.

  • Honest gaps

    Missing, denied, stale and reset measurements keep their labels. A missing value is shown as missing, not as zero.
